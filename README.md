# Java — Programação Orientada a Objetos II

Materiais, exercícios e projetos da disciplina **INE5404 — Programação Orientada a Objetos II**, desenvolvidos em Java.

Este diretório é a fonte oficial do conteúdo. Cada alteração enviada para `main` é espelhada automaticamente, em até alguns minutos, no repositório [`noob-br/java`](https://github.com/noob-br/java).

## Organização sugerida

- `Exercises/`: exercícios e listas.
- `Projects/`: trabalhos e projetos.
- `Notes/`: anotações da disciplina.
